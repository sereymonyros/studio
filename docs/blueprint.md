# **App Name**: Arizona Adventure Planner

## Core Features:

- Activity Input: Add activities to your itinerary with a title, date, and time.
- Itinerary Display: Display the itinerary in chronological order by date and time.
- Local Storage: Persist user's information during their session.
- AI Suggestion: Let the LLM reason as a travel planning tool; suggest interesting related sights near listed points of interest, using geographical proximity and a knowledge base of things to do.

## Style Guidelines:

- Primary color: Sandy brown (#D2B48C) to evoke the desert landscape.
- Background color: Pale beige (#F5F5DC), providing a neutral canvas that evokes sand and natural paper.
- Accent color: Sky blue (#87CEEB) that creates a cool and inviting interface with an airy feel, reminiscent of clear Arizona skies.
- Body and headline font: 'PT Sans', a modern sans-serif font that maintains a little warmth and personality.
- Use simple, clear icons representing common activities (e.g., hiking, dining, landmarks).
- Clean and spacious layout with a focus on readability and easy navigation.
- Subtle transitions when adding or removing activities from the itinerary.
